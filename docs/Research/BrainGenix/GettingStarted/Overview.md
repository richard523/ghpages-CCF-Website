# Getting Started Guide

This quick start guide will give you all the necessary information needed to get you up and running with a working BrainGenix installation.

To get started, please jump into the [requirements document](/GettingStarted/Requirements/) which outlines what software/hardware you will need in order to have a functioning installation.

After that, the [backend installation guide](/GettingStarted/BackendInstallation) will point you to the right resources to get each component installed and configured.

Finally, now that you have the backend setup, please jump over to the [client installation](/GettingStarted/ClientInstallation), which is the main way you'll interact with BG.


!!! note

    The client does not have to be installed on the same machine as the backend - it is network based.
